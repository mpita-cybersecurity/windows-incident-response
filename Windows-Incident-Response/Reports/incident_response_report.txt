4. NETWORK CONNECTIONS

PowerShell was used to identify established TCP connections
on the Windows system.

Command Used:
Get-NetTCPConnection | Where-Object State -eq "Established"

Evidence File:
network_connections.png

Observations:

The process review identified several expected Windows and
Microsoft Edge processes, including msedge, msedgewebview2
and explorer. SynTPEnh was also observed and is associated
with Synaptics hardware software.

PlariumPlay was identified as a third-party gaming application.
The presence of this process alone does not indicate malicious
activity, but unfamiliar third-party software should be verified
during a security investigation.

No process was classified as definitively malicious based on
the process list alone.


The network connection review identified a connection between
127.0.0.1 and 127.0.0.1 on ports 52211 and 52210.

The connection was owned by the 3CXSoftphone process (PID 2196).
Because 127.0.0.1 is the local loopback address, the connection
appears to be internal to the Windows system rather than a direct
external connection.

No malicious activity was identified from this connection alone.
Further investigation would be required if other suspicious
indicators were identified.

5. STARTUP PROGRAMS

Windows startup entries were reviewed to identify programs
configured to start automatically.

Command Used:

Observations:

The startup review identified several expected applications,
including Five9 Softphone Service, WhatsApp Web, Docker Desktop,
PlariumPlay, Microsoft Teams, Microsoft Edge and Avast Browser.

AnyDesk was identified as a startup application. AnyDesk is a
legitimate remote-access application, but remote-access software
should be verified during an incident investigation because
legitimate remote-access tools can potentially be abused by
attackers.

No startup entry was classified as confirmed malicious based on
the startup list alone.

12. Final Incident Assessment

The Windows incident-response investigation examined system information, running processes, network connections, startup applications, Windows System Event Logs and Windows Defender operational events.

The investigation identified several legitimate applications and services operating on the system. These included Microsoft Edge, Windows Explorer, Synaptics software, Microsoft Teams, Docker Desktop, WhatsApp Web, Five9 Softphone Service and Windows Security components.

A 3CXSoftphone process was associated with a local loopback connection between 127.0.0.1 ports 52211 and 52210. Because the connection remained within the local system, it was not considered suspicious based on the available evidence.

AnyDesk was identified as a startup application. Although AnyDesk is legitimate remote-access software, its presence should be verified during a security investigation because remote-access tools can potentially be abused.

No process, network connection, startup application or security event was identified as confirmed malicious based on the evidence collected.

Overall Risk Assessment:
LOW — No confirmed indicators of compromise were identified during this investigation.

Recommended Actions:

* Continue monitoring system activity for unusual processes or connections.
* Keep Windows and security software updated.
* Review remote-access applications such as AnyDesk and disable them if they are not required.
* Investigate future Windows Defender alerts promptly.
* Correlate multiple indicators before determining that a system has been compromised.

Conclusion:
The investigation did not identify sufficient evidence to confirm that the Windows system was compromised. The collected evidence demonstrates a structured incident-response process involving system reconnaissance, process analysis, network analysis, startup analysis, event-log review and security-event investigation.
